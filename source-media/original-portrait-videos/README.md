# Original portrait video exports

These are the untouched portrait-video exports supplied with the project. They are kept outside Vite's `public/` directory so unused 13 MB originals are not copied into production output.

The active hero still uses the same portrait loop, cropped to remove baked-in black letterboxing and re-encoded as fast-start H.264 at `public/images/port1.mp4` (about 0.5 MB). The full-resolution originals remain here for future re-edits.
